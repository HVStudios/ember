# Roadmap

## Phase 0 — Definition and foundation (current)

- Product requirements and explicit non-goals
- Training specification and seed program
- Technical architecture and repository boundaries
- Design-system direction
- Domain contracts and validated seed-data shape
- Low-fidelity mobile flows

Exit: the first vertical slice can be built without unresolved structural decisions.

## Phase 1 — Private MVP vertical slice

- Installable app shell and local database
- Home with next workout
- One complete seed workout rendered from data
- Exercise guide with media placeholders
- Set logging and rest timer
- Draft save/resume
- Workout summary and history

Exit: one real gym session can be completed offline without losing data.

## Phase 2 — Full seed program and progression

- All 3+1 sessions and exercise content
- Curated substitutions
- Previous-performance display
- Double-progression recommendation engine
- Per-exercise history
- Automated domain and persistence tests

Exit: Ember can support the full strength program for four consecutive weeks.

## Phase 3 — Progress and portability

- Body-weight and optional waist log
- Minimal manual run log
- Useful progress views
- JSON export/import
- Data recovery and destructive-data controls
- Light theme and accessibility audit

Exit: user data is understandable, portable, and recoverable.

## Later, only after validated need

- Program editor
- Cloud sync and accounts
- Native wrapper or React Native client
- Health-platform integration
- Rich exercise animation library
- Coach/AI assistance
- Public release and monetization
